** Fennel setup
*** download the fennel runtime, but only if we simply must
Tangling must not require a network connection when a usable runtime already exists.

The bootstrap checks these sources in order:

1. =fennel.lua= beside this Org file.
2. A shared vendored copy at =~/lib/lua/fennel.lua=.
3. The pinned Fennel 1.3.1 download.

A usable local file is a readable, nonempty regular file. Existing local files are trusted; the bootstrap does not check their version or execute them.

Downloads use HTTPS, a 15-second retrieval timeout, and an HTTP status check. A basic body check rejects empty responses and HTML-like error pages. This is not checksum verification.

The bootstrap writes to a temporary file in the destination directory, then renames it into place. A failed fetch cannot leave a partial =fennel.lua=. Temporary filenames do not end in =.lua= or =.fnl=, so the Hammerspoon source watcher ignores them.

If installation fails, tangling continues with a warning. If no runtime is available, Hammerspoon cannot load the generated configuration.

The named block defines and runs the helper. It produces no tangled file and no results text. The following empty block invokes it during tangling, so a fresh Emacs process does not require a manual setup step. Normal Org Babel execution confirmation still applies.

#+name: spoon-forge-ensure-fennel
#+begin_src emacs-lisp :tangle no :results silent :exports none
(defun spoon-forge--usable-runtime-p (file)
  "Return non-nil when FILE is a readable, nonempty regular file."
  (and (file-regular-p file)
       (file-readable-p file)
       (let ((attributes (file-attributes file)))
         (and attributes
              (> (file-attribute-size attributes) 0)))))

(defun spoon-forge--download-fennel (url destination)
  "Download URL into DESTINATION, or signal an error.
DESTINATION must be a temporary file, not the installed runtime."
  (require 'url)
  (require 'url-http)
  (let ((response nil))
    (unwind-protect
        (progn
          (setq response (url-retrieve-synchronously url t t 15))
          (unless (buffer-live-p response)
            (error "No response from %s within the retrieval timeout" url))
          (with-current-buffer response
            (unless (and (boundp 'url-http-response-status)
                         (equal url-http-response-status 200))
              (error "HTTP response was %s"
                     (if (boundp 'url-http-response-status)
                         url-http-response-status
                       "unavailable")))
            (unless (and (boundp 'url-http-end-of-headers)
                         url-http-end-of-headers)
              (error "HTTP response has no header boundary"))
            (goto-char url-http-end-of-headers)
            (let ((body-start (point)))
              (skip-chars-forward " \t\r\n")
              (when (eobp)
                (error "Downloaded fennel runtime is empty"))
              (when (eq (char-after) ?<)
                (error "Downloaded response looks like markup, not Lua"))
              (let ((coding-system-for-write 'no-conversion))
                (write-region body-start (point-max)
                              destination nil 'silent)))))
      (when (buffer-live-p response)
        (kill-buffer response)))))

(defun spoon-forge-ensure-fennel (directory)
  "Ensure DIRECTORY contains fennel.lua without aborting a tangle.
Reuse the installed runtime, then try a shared local copy, then HTTPS.
Return the installed path on success, or nil after a warning."
  (let* ((target (expand-file-name "fennel.lua" directory))
         (shared (expand-file-name "~/lib/lua/fennel.lua"))
         (version "1.3.1")
         (url (format "https://fennel-lang.org/downloads/fennel-%s"
                      version)))
    (if (spoon-forge--usable-runtime-p target)
        target
      (condition-case err
          (let ((temporary
                 (make-temp-file
                  (expand-file-name ".fennel-install-" directory)
                  nil ".tmp")))
            (unwind-protect
                (progn
                  (if (spoon-forge--usable-runtime-p shared)
                      (copy-file shared temporary t)
                    (spoon-forge--download-fennel url temporary))
                  (unless (spoon-forge--usable-runtime-p temporary)
                    (error "Runtime installation produced an unusable file"))
                  (rename-file temporary target t)
                  (message "Spoon Forge: installed %s" target)
                  target)
              (when (file-exists-p temporary)
                (delete-file temporary))))
        (error
         (display-warning
          'spoon-forge
          (format
           (concat "Could not install %s: %s\n"
                   "Tangling will continue, but Hammerspoon needs this runtime.\n"
                   "Place a trusted fennel.lua at %s or %s, then tangle again.")
           target (error-message-string err) target shared)
          :warning)
         nil)))))

(let ((source (buffer-file-name (buffer-base-buffer))))
  (unless source
    (user-error "Save this Org file before bootstrapping Fennel"))
  (spoon-forge-ensure-fennel (file-name-directory source)))
#+end_src

* Keyboard controls
** Floating hint display

Both kinds of hints use the same non-activating =hs.canvas= panel. The panel does not take keyboard focus.

- Modifier hints are visible while an exact modifier chord is held.
- Leader hints stay visible until the leader menu is dismissed.
- Leader hints take priority over modifier hints.

This implementation is self-contained, but was heavily inspired by agzam et al's
Spacehammer project and the [[https://learnhammerspoon.com/chapters/15-floating-hint-menu-for-keybindings/][Floating hint menu for keybindings]] chapter of
learnhammerspoon.com.

*** Canvas implementation

The renderer accepts a title, an array of ={:key ... :label ...}= entries, and a footer. It sorts entries by key and puts long lists into columns.

The screen is selected when the panel is drawn. This first version does not track screen changes while a panel is already visible.

#+begin_src fennel :tangle key-hints.fnl
(var canvas nil)

(fn hide []
  (when canvas
    (canvas:delete)
    (set canvas nil)))

(fn show [title entries footer]
  (hide)
  (table.sort entries (fn [a b] (< a.key b.key)))
  (let [screen (: (hs.screen.mainScreen) :frame)
        line-height 24
        max-rows (math.max 1
                          (math.min 12
                                    (math.floor (/ (- screen.h 140)
                                                   line-height))))
        columns (math.max 1 (math.ceil (/ (# entries) max-rows)))
        rows (math.max 1 (math.min max-rows (# entries)))
        width (math.min (- screen.w 40) (+ 32 (* columns 340)))
        height (+ 92 (* rows line-height))
        column-width (/ (- width 32) columns)]
    (set canvas
         (hs.canvas.new {:x (+ screen.x (/ (- screen.w width) 2))
                         :y (+ screen.y (/ (- screen.h height) 2))
                         :w width
                         :h height}))
    (canvas:level hs.canvas.windowLevels.overlay)
    (canvas:behavior [:canJoinAllSpaces :stationary :ignoresCycle])
    (canvas:clickActivating false)
    (canvas:appendElements
      {:type :rectangle
       :action :fill
       :fillColor {:red 0.08 :green 0.09 :blue 0.12 :alpha 0.96}
       :roundedRectRadii {:xRadius 12 :yRadius 12}}
      {:type :text
       :text title
       :textFont "Menlo"
       :textSize 18
       :textColor {:white 1 :alpha 1}
       :frame {:x 16 :y 12 :w (- width 32) :h 28}})
    (each [i entry (ipairs entries)]
      (let [index (- i 1)
            column (math.floor (/ index max-rows))
            row (% index max-rows)]
        (canvas:appendElements
          {:type :text
           :text (string.format "%-7s %s" entry.key entry.label)
           :textFont "Menlo"
           :textSize 15
           :textColor {:white 0.9 :alpha 1}
           :frame {:x (+ 16 (* column column-width))
                   :y (+ 48 (* row line-height))
                   :w (- column-width 12)
                   :h line-height}})))
    (canvas:appendElements
      {:type :text
       :text footer
       :textFont "Menlo"
       :textSize 12
       :textColor {:white 0.65 :alpha 1}
       :frame {:x 16 :y (- height 28) :w (- width 32) :h 20}})
    (canvas:show)))

** Modifier binding helpers

Valid key strings are any single-character string, or any of the following strings:

- f1, f2, f3, f4, f5, f6, f7, f8, f9, f10, f11, f12,
  f13, f14, f15, f16, f17, f18, f19, f20

- pad0, pad1, pad2, pad3, pad4, pad5, pad6, pad7, pad8, pad9

- shift, rightshift, cmd, rightcmd, alt, rightalt, ctrl, rightctrl

The existing two-argument calls still work. An optional third argument supplies the hint:

Without a description, the hint displays the key itself.

*** Binding registry

The numeric IDs encode Cmd, Alt, Ctrl, and Shift as 1, 2, 4, and 8. This lets the modifier watcher select an exact group without relying on table iteration order.

#+begin_src fennel :tangle keybindings.fnl
(local hints (require :key-hints))

(var leader-active false)

(local modifier-groups
       {3  {:title "puppy-paw · Cmd+Alt"
            :mods [:cmd :alt]
            :entries {}}
        11 {:title "PUPPY-PAW · Cmd+Alt+Shift"
            :mods [:cmd :alt :shift]
            :entries {}}
        7  {:title "bearclaw · Cmd+Alt+Ctrl"
            :mods [:cmd :alt :ctrl]
            :entries {}}

            :mods [:cmd :alt :ctrl :shift]

(fn bind-modifiers [id key func description]
  (let [group (. modifier-groups id)
        binding (hs.hotkey.bind group.mods key func)]
    (when binding
      (tset group.entries key {:key key

*** Hints while modifiers are held

The watcher observes modifier changes; it does not consume events.

Releasing a modifier hides the panel or switches to the newly held chord. For example, releasing Shift from =BEARCLAW= shows =bearclaw= if Cmd, Alt, and Ctrl remain held.

Caps Lock does not affect group selection. Fn suppresses modifier hints. The leader menu suppresses modifier hints until it exits.

#+begin_src fennel :tangle keybindings.fnl
(fn modifier-id [flags]
  (+ (if flags.cmd 1 0)
     (if flags.alt 2 0)
     (if flags.ctrl 4 0)
     (if flags.shift 8 0)))

(fn refresh-held-hints [flags]
  (when (not leader-active)
    (let [group (and (not flags.fn)
                     (. modifier-groups (modifier-id flags)))]
      (if group
          (let [entries []]
            (each [_ entry (pairs group.entries)]
              (table.insert entries entry))
            (if (> (# entries) 0)
                (hints.show group.title entries "Release modifiers to dismiss")
                (hints.hide)))
          (hints.hide)))))

(local modifier-watcher
       (: (hs.eventtap.new
            [hs.eventtap.event.types.flagsChanged]
            (fn [event]
              (refresh-held-hints (event:getFlags))
              false))
          :start))
#+end_src

** Prefix map

=Cmd+Alt+Space= opens the leader menu in one-shot mode; =Cmd+Alt+Ctrl+Space= opens it in persistent mode. Release the activation modifiers before typing a menu path.

- =Escape= dismisses the menu.
- =Delete= goes to the parent menu; at the root, it dismisses the menu.
- Either activation chord also toggles the menu off.
- =Ctrl+Space= switches an open menu between one-shot and persistent modes.
- Selecting a prefix shows its children.
- Running a command closes a one-shot menu and leaves a persistent menu open.
- There is no timeout.

*** Key-defining API

=spacehammer= accepts a path, a function, and a hint. Strings represent sequences of single-character keys:

#+begin_example
(spacehammer :w nil "Windows")
(spacehammer :wl window/right "Focus right")
#+end_example

Invoke the second binding with =Cmd+Alt+Ctrl+Space=, then =w l=.

Use a vector for named keys and modified keys:

#+begin_example
(spacehammer [:w :right] window/right "Focus right")
(spacehammer [:w :C-l] window/right "Focus right")
#+end_example

A nil function declares a prefix. Prefix declarations are optional, but they give the menu a useful name. Missing prefixes are created automatically.

=Escape= and =Delete= are reserved for navigation. A path cannot be both a command and a prefix. Re-registering an existing command replaces its function and, when supplied, its hint.

=spacehammer-prefix= returns a binding helper whose paths are relative to a prefix. Its optional second argument names that prefix in the menu:

#+begin_example
(local windows-prefix (spacehammer-prefix :w "Windows"))
(windows-prefix :l window/right "Focus right")
#+end_example

This is equivalent to:

#+begin_example
(spacehammer :w nil "Windows")
(local windows-prefix (spacehammer-prefix :w))
(windows-prefix :l window/right "Focus right")
#+end_example

An optional third argument attaches hooks, e.g. for functions that run when the prefix submenu is entered and left:

#+begin_example
(spacehammer-prefix :w "Windows" {:on-enter show-overlay :on-exit hide-overlay})
#+end_example

Without a description, creating the helper does not register or rename a menu entry. Its first binding creates any missing prefixes, just as =spacehammer= does.

With a description, the prefix is registered immediately, even if it has no children yet. An existing prefix keeps its children and receives the supplied label. An existing command cannot be declared as a prefix.

Both the prefix and the relative paths accept strings or vectors. The returned helper has the same arguments and return value as =spacehammer=.

*** Menu state and navigation

=hammer= owns the keyboard modal. A separate tree stores bindings and descriptions. The stack records the current route through that tree.

#+begin_src fennel :tangle keybindings.fnl
(local hammer (hs.hotkey.modal.new))
(local menu-root {:label "Spacehammer" :children {}})
(var menu-stack [menu-root])
(var persistent false)
(local bound-menu-keys {})

(local chord-modifiers {:C :ctrl :M :alt :s :cmd :S :shift})

(fn key-chord [key]
  "Split an Emacs-style KEY such as \"C-M-h\" into a set of modifiers and a key."
  (let [mods {}]
    (var base key)
    (while (string.match base "^[CMsS]%-.")
      (tset mods (. chord-modifiers (base:sub 1 1)) true)
      (set base (base:sub 3)))
    (values mods base)))

(fn canonical-key [key]
  "Rewrite KEY's modifiers in C-M-S-s- order, without duplicates."
  (let [(mods base) (key-chord key)]
    (.. (if mods.ctrl "C-" "")
        (if mods.alt "M-" "")
        (if mods.shift "S-" "")
        (if mods.cmd "s-" "")
        base)))

(fn key-label [key]
  (let [(mods base) (key-chord key)]
    (.. (if mods.ctrl "⌃" "")
        (if mods.alt "⌥" "")
        (if mods.shift "⇧" "")
        (if mods.cmd "⌘" "")
        base)))

(fn current-menu []
  (. menu-stack (# menu-stack)))

(fn draw-leader []
  (let [entries []
        route []]
    (each [_ node (ipairs menu-stack)]
      (table.insert route node.label))
    (each [key node (pairs (. (current-menu) :children))]
      (table.insert entries
                    {:key (key-label key)
                     :label (.. node.label
                                (if node.action "" " ›"))}))
    (hints.show (table.concat route " / ")
                entries
                (.. "Esc: close   Delete: back   Ctrl+Space: "
                    (if persistent
                        "one-shot (now persistent)"
                        "persistent (now one-shot)")))))

(fn run-hooks [node hook]
  (each [_ func (ipairs (or (?. node :-hooks hook) []))]
    (func)))

(fn enter-menu [node]
  (table.insert menu-stack node)
  (run-hooks node :on-enter))

(fn leave-menu []
  (run-hooks (table.remove menu-stack) :on-exit))

(tset hammer :entered
      (fn []
        (set leader-active true)
        (set menu-stack [menu-root])
        (draw-leader)))

(tset hammer :exited
      (fn []
        (set leader-active false)
        (while (> (# menu-stack) 1)
          (leave-menu))
        (refresh-held-hints (hs.eventtap.checkKeyboardModifiers))))

(hammer:bind [] :escape nil #(hammer:exit))

(hammer:bind [] :delete nil
             (fn []
               (if (> (# menu-stack) 1)
                   (do
                     (leave-menu)
                     (draw-leader))
                   (hammer:exit))))

(hammer:bind [:ctrl] :space nil
             (fn []
               (set persistent (not persistent))
               (draw-leader)))

(fn toggle-leader [mode-persistent]
  (if leader-active
      (hammer:exit)
      (do
        (set persistent mode-persistent)
        (hammer:enter))))

(puppy-paw :space #(toggle-leader false) "Leader menu (one-shot)")
(bearclaw :space #(toggle-leader true) "Leader menu (persistent)")
#+end_src

*** Paths and registration

String paths use ASCII characters. Vector paths can use named Hammerspoon keys and Emacs-style modifier prefixes: =C-= is Ctrl, =M-= is Alt, =s-= is Cmd and =S-= is Shift, e.g. =[:C-h]= or =[:C-M-return]=. The hint panel shows modifiers as Mac symbols, e.g. =⌃h=.

Each distinct key has one modal binding. Its callback looks up the key in the current menu, so the same key can perform different actions in different branches.

This first version is not a general keyboard event filter:

- A registered menu key with no entry in the current branch does nothing.
- Other keys can still reach the focused application.
- =C-space= is reserved for the persistence toggle.

#+begin_src fennel :tangle keybindings.fnl
(fn path-keys [path]
  (let [keys []]
    (match (type path)
      :string
      (each [key (string.gmatch path ".")]
        (table.insert keys key))

      :table
      (each [_ key (ipairs path)]
        (table.insert keys (canonical-key key)))

      _
      (error "A leader path must be a string or a vector."))
    (assert (> (# keys) 0) "A leader path cannot be empty.")
    (each [_ key (ipairs keys)]
      (assert (and (= (type key) :string)
                   (> (# key) 0))
              "Each leader key must be a nonempty string.")
      (assert (and (~= (string.lower key) :escape)
                   (~= (string.lower key) :delete)
                   (~= key :C-space))
              "Escape, Delete and C-space are reserved for menu navigation."))
    keys))

(fn dispatch-menu-key [key]
  (let [node (. (current-menu) :children key)]
    (when node
      (if node.action
          (do
            (when (not persistent)
              (hammer:exit))
            (node.action))
          (do
            (enter-menu node)
            (draw-leader))))))

(fn bind-menu-key [key]
  (when (not (. bound-menu-keys key))
    (let [(mods base) (key-chord key)]
      (hammer:bind (icollect [mod (pairs mods)] mod) base nil #(dispatch-menu-key key)))
    (tset bound-menu-keys key true)))

(fn spacehammer [path action description]
  "Bind a leader path, or name a prefix when ACTION is nil."
  (assert (or (= action nil) (= (type action) :function))
          "A leader action must be a function or nil.")
  (let [keys (path-keys path)]
    (var node menu-root)
    (each [_ key (ipairs keys)]
      (assert (not node.action)
              "A leader command cannot also contain child bindings.")
      (when (not (. node.children key))
        (tset node.children key {:label key :children {}}))
      (set node (. node.children key)))
    (if action
        (do
          (assert (= (next node.children) nil)
                  "A leader prefix cannot also be a command.")
          (tset node :action action))
        (assert (not node.action)
                "Cannot name a command as a prefix."))
    (when description
      (tset node :label description))
    (each [_ key (ipairs keys)]
      (bind-menu-key key))
    (when leader-active
      (draw-leader))
    node))
#+end_src

*** Prefix hooks

A prefix node stores its hooks under =:-hooks=, as a map from hook name to a list of functions. =spacehammer-add-hook= appends a function to one of those lists, creating the prefix if needed.

The navigation code runs two hooks:

- =:on-enter= runs when the prefix is entered, before the menu is drawn, so it can register children for that prefix.
- =:on-exit= runs when the prefix is left: =Delete=, =Escape=, the activation chord, or a one-shot command closing the menu.

#+begin_src fennel :tangle keybindings.fnl
(fn spacehammer-add-hook [menu hook func]
  "Append FUNC to the HOOK functions, e.g. :on-enter, of the prefix at path MENU."
  (let [node (spacehammer menu nil)
        hooks (or (. node :-hooks) {})]
    (tset node :-hooks hooks)
    (when (not (. hooks hook))
      (tset hooks hook []))
    (table.insert (. hooks hook) func)
    node))
#+end_src

*** Relative binding helper

=spacehammer-prefix= replaces =in-prefix=. It uses =spacehammer= to register an optional description and =spacehammer-add-hook= to attach optional hooks, so prefix validation and hint updates follow the same rules as direct registrations.

The helper copies the prefix keys when it is created. Each call builds a fresh combined path.

#+begin_src fennel :tangle keybindings.fnl
(fn spacehammer-prefix [prefix description hooks]
  "Return a relative binding helper; optionally name PREFIX in the menu
and attach HOOKS of the form {:on-enter f :on-exit g} to it."
  (assert (or (= description nil) (= (type description) :string))
          "A prefix description must be a string or nil.")
  (let [base (path-keys prefix)]
    (when (~= description nil)
      (spacehammer base nil description))
    (each [hook func (pairs (or hooks {}))]
      (spacehammer-add-hook base hook func))
    (fn [path action description]
      (let [keys []]
        (each [_ key (ipairs base)]
          (table.insert keys key))
        (each [_ key (ipairs (path-keys path))]
          (table.insert keys key))
        (spacehammer keys action description)))))
#+end_src

A relative helper can also declare nested prefixes:

#+begin_example
(local windows-prefix (spacehammer-prefix :w "Windows"))
(windows-prefix :p nil "Placement")
(windows-prefix :pl window/right-half "Right half")
#+end_example

For a separate helper at the nested prefix, supply its full path:

#+begin_example
(local placement-prefix (spacehammer-prefix :wp "Placement"))
(placement-prefix :l window/right-half "Right half")
#+end_example

** Directional focus and width resizing

Width steps are 10% of the screen width. The width stays between one step and the full screen width, and the window shifts left if needed to stay on screen.

#+begin_src fennel :tangle windows.fnl
(local window/left #(: (current) :focusWindowWest))
(local window/right #(: (current) :focusWindowEast))
(local window/up #(: (current) :focusWindowNorth))
(local window/down #(: (current) :focusWindowSouth))
(fn width-stepper [steps]
  (window-resizer (fn [window screen]
                    (let [step (* 0.1 screen.w)]
                      (set window.w (math.min screen.w
                                              (math.max step (+ window.w (* steps step)))))
                      (set window.x (math.min window.x
                                              (+ screen.x (- screen.w window.w))))))))

(local window/enlarge (width-stepper 1))
(local window/shrink (width-stepper -1))
#+end_src

=window/choose= lists windows in a chooser, most recently used first. The query is split on spaces, and each word must match the title or app name with its letters in order, e.g. =ff gh= matches a Firefox window titled "GitHub".

#+begin_src fennel :tangle windows.fnl
(var window-choices [])
(var chooser-windows {})

(fn fuzzy-pattern [word]
  (pick-values 1 (word:gsub "." #(.. (if (string.match $ "%w") $ (.. "%" $)) ".-"))))

(fn fuzzy-match? [query text]
  (let [text (text:lower)]
    (accumulate [matched true word (string.gmatch (query:lower) "%S+")]
      (and matched (not= nil (string.find text (fuzzy-pattern word)))))))

(local window-chooser
       (hs.chooser.new (fn [choice]
                         (let [win (and choice (. chooser-windows choice.id))]
                           (when win (win:focus))))))

(window-chooser:queryChangedCallback
 (fn [query]
   (window-chooser:choices
    (icollect [_ choice (ipairs window-choices)]
      (when (fuzzy-match? query (.. choice.text " " choice.subText))
        choice)))))

(fn show-window-chooser [windows]
  (set chooser-windows {})
  (set window-choices
       (icollect [_ win (ipairs windows)]
         (let [app (win:application)]
           (tset chooser-windows (win:id) win)
           {:text (win:title)
            :subText (app:name)
            :image (hs.image.imageFromAppBundle (app:bundleID))
            :id (win:id)})))
  (window-chooser:query "")
  (window-chooser:choices window-choices)
  (window-chooser:show))

(fn window/choose []
  (show-window-chooser (jumpable-windows)))
#+end_src
